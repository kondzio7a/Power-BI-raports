# UEFA EURO 2024 Power BI Dashboard

This project presents an interactive **Power BI dashboard** focused on the analysis of players participating in **UEFA EURO 2024**.

The main goal of the project is to transform raw football player data into a clear and interactive report that allows users to analyze players, national teams, clubs, market values, positions, and other statistics.

The dashboard was created using **Power BI**, with data preparation performed in **Power Query** and calculations created using **DAX**.

## Tools & Technologies

- **Power BI** – dashboard design and data visualization
- **Power Query** – data cleaning and transformation
- **DAX** – measures, calculations, and KPIs
- **CSV** – source dataset containing EURO 2024 player data

## Dataset Description

The dataset contains information about players participating in **UEFA EURO 2024**.

It includes player characteristics, international statistics, club information, and estimated market values.

The dataset includes information such as:

- **Name** – player's full name
- **Position** – player's position on the field
- **Age** – player's age
- **Club** – club represented by the player
- **Height** – player's height in centimeters
- **Foot** – preferred foot: right, left, or both
- **Caps** – number of appearances for the national team
- **Goals** – number of goals scored for the national team
- **Market Value** – estimated market value of the player
- **Country** – national team represented by the player

## Dashboard Features

The dashboard provides an interactive overview of EURO 2024 players.

### National Team Market Value

The dashboard compares the total market value of players representing each national team.

This visualization makes it possible to compare the overall squad values of countries participating in EURO 2024.

### Club Market Value

The dashboard also presents the total market value of EURO 2024 players grouped by their clubs.

This allows users to identify which football clubs have the highest-value players participating in the tournament.

### Top Scorer

A dedicated section highlights the player with the highest number of international goals in the dataset.

The dashboard displays:

- Player name
- Number of goals
- Height
- Position

### Player Overview

An interactive table allows users to explore individual players and compare information such as:

- **Name**
- **Club**
- **Age**
- **Height**
- **Position**

### Player Location

A map visualization presents the geographical distribution of players based on their national teams.

Players can also be filtered by their preferred foot:

- **Right**
- **Left**
- **Both**

### Interactive Filters

The dashboard includes interactive slicers that allow users to dynamically filter the report and explore selected groups of players.

## Project Workflow
